# Overrun robot sound pack

Every `.wav` in this directory is generated by
[`tools/generate_robot_audio.py`](../../tools/generate_robot_audio.py). The
script uses only Python's standard library and produces deterministic 44.1 kHz,
mono, 16-bit PCM audio. No external samples are required.

The sound language follows the robot graphics pass:

- Player weapons use clean cyan-energy sweeps and restrained metallic attacks.
- Enemy weapons and damage use rougher oscillators and darker metal noise.
- Boss events use low machinery, alarms, and heavy core impacts.
- UI and progression use short digital tones and servo clicks.

Regenerate the full pack with:

```bash
python3 tools/generate_robot_audio.py
```

Cue volumes, pitch variation, cooldowns, and voice priorities live in
`src/sound_manager.gd`. Frequent crowd cues have low priority and are dropped
rather than replacing boss warnings, player-damage alerts, or progression
confirmations when the 24-voice pool is saturated.

`tools/measure_audio_band.py` reports duration, RMS/peak level, and rough high-
and low-frequency energy for mix checks.
